# static2fate

Can a single still image of a drug-treated cell tell us whether it will die, and when that became decided?

Static2Dynamic (Boyer et al., 2026) turns snapshots into a video of one process. This project asks
what happens when there are two futures. Starting point: HeLa cells under a staurosporine dose
response (S-BIAD2515), where every cell has a known fate from a terminal AnnexinV stain and a
six-hour video, so generated futures can be checked against real ones.
